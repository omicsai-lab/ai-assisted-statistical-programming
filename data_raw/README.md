# Synthetic datasets

These CSV files are small synthetic teaching datasets used by the R and Python examples.

- `clinic_visits.csv` — patient visit-style data with group labels, baseline/follow-up values, and intentional missing values.
- `practice.csv` — a small practice dataset for simple inspection and cleaning tasks.
- `wellness.csv` — a shared dataset used in Chapter 16 to compare the same analysis in R and Python.

The data are not real patient data and should not be interpreted clinically.
