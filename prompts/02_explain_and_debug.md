# Explain and debug prompts

## Explain code

```text
Please explain this code line by line. Focus on what each step does to the dataset, what output I should expect, and what I should check before trusting the result.
```

## Debug code

```text
This code gives the following error message. Please explain what the error means, suggest two possible causes, and show the smallest change I should test first.
```

## Prompt repair

```text
Here is my original prompt and the answer I received. Please identify what was missing from my prompt, what assumptions the answer made, and how to rewrite the prompt so the assistant asks fewer questions and makes fewer guesses.
```
