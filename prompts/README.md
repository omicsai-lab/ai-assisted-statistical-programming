# Prompt library

These prompt templates are designed for AI-assisted statistical programming. They are not meant to make the AI assistant the final authority. Use them to request drafts, explanations, critiques, debugging help, and verification checklists.

Recommended pattern:

1. Provide the task, language, packages, data object name, variables, and outcome.
2. Ask for small steps rather than a long unreviewed script.
3. Ask the assistant to list assumptions and checks.
4. Run the code yourself.
5. Verify row counts, missing values, denominators, and model assumptions.
6. Document how AI was used.
