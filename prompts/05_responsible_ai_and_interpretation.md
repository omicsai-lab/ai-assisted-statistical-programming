# Responsible AI and interpretation prompts

## Responsible AI review

```text
Please act as a cautious reviewer. Identify any privacy risks, hallucinated functions, hidden assumptions, missing-value issues, sample-size concerns, or overinterpretation in this AI-assisted code and explanation.
```

## Interpretation audit

```text
Please review this statistical interpretation for overclaiming. Identify causal language, missing uncertainty, missing sample-size information, unsupported practical conclusions, and wording that may confuse nontechnical readers. Suggest a cautious rewrite.
```

## AI-use disclosure draft

```text
Please help me draft a short AI-use disclosure for this analysis. The disclosure should state that AI was used for code drafting, debugging, and explanation, but that I reviewed the code, ran the analysis, checked outputs, and remain responsible for the final interpretation.
```
